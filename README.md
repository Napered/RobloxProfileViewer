# RobloxProfileViewer

Roblox 사용자 프로필 조회 프로그램입니다. 사용자 이름 또는 ID를 입력하여 공개 프로필과 관련 정보를 간편하게 확인할 수 있습니다.

## 주요 기능

- Roblox 사용자 이름 및 ID 검색
- 공개 프로필 및 아바타 조회
- 계정 생성일 확인
- 친구, 팔로워, 팔로잉 수 확인

## 이용약관 및 안내

1. **서비스 범위**  
   본 프로그램은 Roblox의 공개 프로필 정보만 조회하는 독립 도구입니다. 비공개 정보나 계정 접근 권한을 제공하지 않습니다.

2. **개인정보 및 데이터**  
   검색한 사용자 이름 또는 ID는 Roblox 공개 API로 전송됩니다. 프로그램은 검색값이나 조회 결과를 별도로 저장하지 않으며, 로그인 정보나 비밀번호를 요구하지 않습니다.

3. **사용 제한**  
   조회 정보는 개인적인 참고 목적으로 사용해야 합니다. 괴롭힘, 개인정보 침해, 접근 제한 우회 또는 법률 및 Roblox 규칙을 위반하는 목적으로 사용할 수 없습니다.

4. **정보의 정확성 및 서비스**  
   조회 결과는 Roblox가 제공하는 공개 데이터를 기반으로 하며, 변경되거나 일부 누락될 수 있습니다. API 제한, 네트워크 문제 및 서비스 변경으로 조회가 실패할 수 있습니다.

5. **비공식 프로그램 안내**  
   본 프로그램은 Roblox Corporation과 제휴하거나 공식적으로 승인받은 서비스가 아닙니다. Roblox 명칭 및 관련 상표는 각 권리자에게 귀속됩니다.

# English

RobloxProfileViewer is a tool that allows users to easily look up public Roblox profiles and related information using a username or user ID.

## Key Features

- Search Roblox users by username or user ID
- View public profiles and avatars
- Check account creation dates
- View friend, follower, and following counts

## Terms of Use

1. **Service Scope**  
   This program is an independent tool that retrieves publicly available Roblox profile information. It does not provide access to private information or user accounts.

2. **Data and Privacy**  
   Search terms are sent directly to the Roblox public API. This program does not separately store search queries or retrieved results and never requests Roblox login credentials or passwords.

3. **Acceptable Use**  
   Information should be used for personal reference only. Harassment, privacy violations, bypassing access restrictions, or any use that violates applicable laws or Roblox rules is prohibited.

4. **Data Accuracy and Availability**  
   Information is based on publicly available data provided by Roblox and may change or be incomplete. Searches may fail due to API limits, network issues, or changes to Roblox services.

5. **Unofficial Status**  
   This program is not affiliated with or officially endorsed by Roblox Corporation. Roblox names and trademarks belong to their respective owners.
